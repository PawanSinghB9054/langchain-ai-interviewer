# 🤖 AI Mock Interviewer

Ye ek simple AI-powered interviewing web app hai jo **Flask**, **LangChain**, aur **Mistral AI** use karke banayi hai. Basically ye aapke resume ya kisi specific topic ke hisab se real-time me technical interview leti hai aur last me feedback aur score bhi deti hai.

---

## ✨ Features

- 📄 **Resume/Topic Support:** Aap jo topic ya resume doge, uske hisab se questions generate hote hain.
- 💬 **Interactive Chat UI:** Clean aur simple interface hai real-time conversation ke liye.
- 🤖 **Smart Evaluation:** Mistral AI aur LangChain use karke follow-up questions aur answer checking hoti hai.
- 📊 **Instant Scoring:** Interview khatam hone par final score, strengths aur improvements pata chalte hain.

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask, Gunicorn
- **AI/LLM:** LangChain, Mistral AI (`langchain-mistralai`)
- **PDF & Embeddings:** ChromaDB, PyPDF
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render
